# Изменения в версии 2.29.0.0

1. Исправлены найденные ошибки при работе с маркировкой и взаимодействие с ЕСП.

2. Добавлен контроль статусов кодов маркировки, оптимизирован интерфейс данного раздела.
   
3. Улучшено быстродействие основных функций при работе с заказами, оперативными задачами, МЛ и реализациями. Оптимизированы регистры.
   
4. Исправлены найденные ошибки при работе с печатными формами и документами по ЭДО.
   
5. Доработаны отчеты по таре и отчет продажи, изменен вывод детализации по умолчанию, теперь детализация до документа идет по двойному клику, это сделано в рамках оптимизации работы отчетов.
   
6. Обновлен и расширен механизм учета загрузки интервалов. Добавлена настройка для дней недели, а так же конкретной даты, добавлен показатель количества бутылей, переработан внешний вид и интерфейс настройки.
