# Ограничения по интервалам

Для повышения эффективности логистики вы можете воспользоваться [!badge variant="light" text="Ограничением по интервалам"].
Оно будет работать, согласно выставленным параметрам в настройках и если будет превышение установленных настроек, то в при создании [!badge variant="light" text="Заказа покупателя"] выйдет надпись в верхнем правом углу:

![](\images\логистика\орг4.jpg)

Установить [!badge variant="light" text="Ограничение по интервалам"] можно в [!badge variant="light" text="Рабочем месте логиста"], нажав на кнопку: 

![](\images\логистика\огр.jpg)

Откроется окно с настройками

![](\images\логистика\огр1.jpg)

Можно установить разные виды ограничений: [!badge variant="light" text="Ограничивать интервалы по маршрутам"], [!badge variant="light" text="Ограничивать по дням недели"], [!badge variant="light" text="Ограничение по дням"].

Рассмотрим каждый по отдельности:

+++ Ограничивать интервалы по маршрутам

Данный вид ограничения предназначен для контроля загрузки автомобиля по количеству товара и веса, а так же контроля точек доставки по маршрутам доставки и их интервалам.

![](\images\логистика\орг2.jpg)

Для того, что бы установить контроль по маршрутным листам нужно установить галочку [!badge variant="light" text="Ограничивать интервалы по маршрутам"].

Далее нажимаем кнопку [!badge variant="light" text="Создать"]. 

![](\images\логистика\орг3.jpg) 

Указываем в строках:

[!badge variant="light" text="Маршрут"] маршрут на который нужно установить ограничение;

[!badge variant="light" text="Интервал"] интервал на который нужно установить ограничение;

[!badge variant="light" text="Заявок"] допустимое количество;

[!badge variant="light" text="Бутылей"] допустимое количество;

[!badge variant="light" text="Вес"] допустимое количество;

[!badge variant="light" text="Дата"] не ставится;

Далее нажимаете [!badge variant="light" text="Записать закрыть"].

Настройки можно сделать по каждому маршрутному листу и по принадлежавшим ему интервалам.

+++ Ограничивать по дням недели

Данный вид ограничения предназначен для контроля загрузки автомобиля по количеству товара и веса только по интервалам, по выбранным дням недели.
Ограничение будет действовать на маршруты, в заявках которых указан выбранный интервал.

Для того, что бы установить контроль по дням недели нужно установить галочку [!badge variant="light" text="Ограничивать по дням недели"].

![](\images\логистика\орг5.jpg)

Далее нажимаем кнопку [!badge variant="light" text="Создать"]. 

![](\images\логистика\орг6.jpg) 

Указываем в строках:

[!badge variant="light" text="День недели"] указывается день в цифрах (порядковый номер дня), например: понедельник равен 1, вторник равен 2;

[!badge variant="light" text="Интервал"] интервал на который нужно установить ограничение;

[!badge variant="light" text="Заявок"] допустимое количество;

[!badge variant="light" text="Бутылей"] допустимое количество;

[!badge variant="light" text="Вес"] допустимое количество;

[!badge variant="light" text="Дата"] не ставится;

Далее нажимаете [!badge variant="light" text="Записать закрыть"].

+++ Ограничение по дням

Данный вид ограничения предназначен для контроля загрузки автомобиля по количеству товара и веса только по интервалам на выбранную дату, например, праздничные дни.
Ограничение будет действовать на маршруты, в заявках которых указан выбранный интервал.

Для того, что бы установить контроль по дням недели нужно установить галочку [!badge variant="light" text="Ограничивать по дням недели"].

![](\images\логистика\орг7.jpg)

Далее нажимаем кнопку [!badge variant="light" text="Создать"]. 

![](\images\логистика\орг8.jpg) 

Указываем в строках:

[!badge variant="light" text="Дата"] устанавливается дата на которую нужно настроить ограничения по интервалу;

[!badge variant="light" text="Интервал"] интервал на который нужно установить ограничение;

[!badge variant="light" text="Заявок"] допустимое количество;

[!badge variant="light" text="Бутылей"] допустимое количество;

[!badge variant="light" text="Вес"] допустимое количество;

Далее нажимаете [!badge variant="light" text="Записать закрыть"].
